# PROJET FINAL : Memory en console

**Objectif : Créer un memory en console structuré en fonctions propres**

__________
Un jeu uniquement en console.\
Une seule partie fonctionnant sur une boucle infinie.\
La grille du memory est en 4x4.\
Les cartes seront codées en dur dans le fichier (l'aléatoire n'ayant pas été abordé dans le chapitre 1).
__________

*Notions révisées :*
- boucle ``while``
- boucle infinie
- tableaux
- ``string``
- ``cout`` et ``cin``
- fonctions
- organisation du code en petites fonctions
